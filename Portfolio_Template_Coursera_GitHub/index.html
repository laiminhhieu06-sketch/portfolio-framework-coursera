04 / QUICK QUESTIONS

Good things
to know.

Open each question to see the answer.

What template is this based on? +

This site adapts the official Bootstrap 5 starter template and customizes the grid, layout, typography, illustration and interaction.

Does the design work on phones? +

Yes. Responsive breakpoints stack cards vertically, adjust the hero layout and switch the navigation to a compact menu.

Is the contact form connected to an inbox? +

No. This demonstration validates inputs in the browser only and does not send messages or store personal information.
